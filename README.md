## 🌟 프로젝트 소개

**우리들의 웹사이트 스튜디오**는 복잡한 코딩이나 외부 프레임워크 없이, 브라우저에서 사진과 문구, 기관 정보만 입력하면 우리 어린이집만의 아름다운 8페이지 반응형 홈페이지를 손쉽게 완성할 수 있는 독립형 웹 애플리케이션(PWA)입니다.

### 🌿 디자인 컬렉션: 아홉 가지 아름다운 이야기 (9종 모델)

시설의 규모보다 배려, 온정, 친밀감, 신뢰를 핵심 가치로 삼아 3가지 테마 스타일과 3가지 사이트 구도를 결합한 9종의 고유 디자인을 제공합니다.

| 스타일 그룹 | 모델명 | 구도 유형 | 주요 특징 |
| :--- | :--- | :--- | :--- |
| **A. 온정과 친밀** | **A-1 따뜻한 마음** *(기본)* | 사진 중심형 | 부드러운 살구·테라코타 톤, 따뜻한 교감 사진과 비대칭 배치 |
| | **A-2 아이의 마음** | 이야기 중심형 | 편안한 라벤더·올리브 톤, 아이의 시선으로 풀어내는 하루 이야기 |
| | **A-3 작은 호기심** | 교육 중심형 | 크림·민트 톤, 놀이 중심의 언어 및 수리 활동 강조 |
| **B. 자연과 성장** | **B-1 아름다운 계절** | 사진 중심형 | 세이지 그린·자연 식물 SVG, 계절의 변화와 자연 친화적 일상 |
| | **B-2 새싹의 이야기** | 이야기 중심형 | 숲의 초록·성장 일기 구도, 아이들의 작은 성장 기록 |
| | **B-3 작은 탐험가** | 교육 중심형 | 자연 탐색·호기심 중심, 관찰과 발견의 배움 이야기 |
| **C. 배움과 미래** | **C-1 행복한 순간** | 사진 중심형 | 별·무지개·구름 SVG, 밝고 경쾌한 격자형 갤러리 |
| | **C-2 눈부신 내일** | 이야기 중심형 | 별자리와 밤하늘 감성, 꿈과 내일을 향한 세 가지 이야기 |
| | **C-3 배움의 세계** | 교육 중심형 | 순백·민트·노랑 톤, 즐거운 언어 표현과 수리 감각 놀이 |

## ✨ 핵심 기능

1. **8개 필수 페이지 완벽 지원**:
   - 홈 (`index.html`), 소개 (`about.html`), 선생님 (`teachers.html`), 언어와 수리 (`learning.html`), 하루 (`daily.html`), 안전 (`safety.html`), 부모님 (`parents.html`), 오시는 길 (`location.html`)
2. **실시간 미리보기 & 반응형 뷰포트**:
   - 데스크톱(1200px) 및 스마트폰(375px) 화면 크기를 실시간으로 전환하며 편집 결과 확인
   - 원클릭 확대·축소 및 화면 맞춤(Fit) 기능
3. **독립된 데이터 보존 및 격리 (Schema v2)**:
   - 기관 기본 정보(이름, 원장명, 주소, 전화번호, 운영시간, 지도) 및 로고는 모델 간 공통 공유
   - 모델별 사진(24자리)과 문구는 독립 저장소에 안전하게 격리 보존되어 디자인 전환 시에도 데이터가 섞이지 않음
4. **로컬 저장 & 폴더 연결**:
   - 브라우저 로컬 저장소(IndexedDB) 실시간 자동 저장
   - 로컬 폴더(File System Access API) 연결 지원으로 안전한 작업 파일 및 백업 자동 관리
   - 폴더 연결 미지원 환경(스마트폰/태블릿)을 위한 작업 JSON 다운로드/불러오기 대체 지원
5. **독립형 정적 홈페이지 즉시 완성 (ZIP 다운로드)**:
   - 외부 라이브러리나 런타임 종속성이 전혀 없는 순수 표준 HTML5/CSS3/JavaScript 정적 사이트 출력
   - 편집 속성 및 시연 데이터를 완전히 제거한 깨끗한 완성본 생성
   - Cloudflare Pages 등 무료 정적 호스팅 서비스 직접 업로드 지원
6. **PWA (Progressive Web App) 오프라인 지원**:
   - 서비스 워커 기반 9종 모델 72페이지 및 필수 자산 100% 오프라인 캐싱
   - PC(Chrome/Edge) 및 스마트폰(iOS/Android) 홈 화면 앱 설치 지원

## 🚀 빠른 시작

### 온라인에서 바로 실행하기
GitHub Pages를 통해 별도의 설치 없이 브라우저에서 바로 사용하실 수 있습니다:
👉 **[우리들의 웹사이트 스튜디오 열기](https://gimmjune.github.io/website-studio/)**

### 로컬 환경에서 실행하기
정적 웹 서버(Python, Node.js 등)를 통해 로컬에서 실행할 수 있습니다:

```bash
# 저장소 클론
git clone https://github.com/gimmjune/website-studio.git
cd website-studio

# 로컬 웹 서버 실행 (Python 3 기준)
python -m http.server 8000
```
브라우저에서 `http://localhost:8000/` 또는 `http://localhost:8000/studio.html`로 접속합니다.
